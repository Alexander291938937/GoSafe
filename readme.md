# GoSafe — Releases Archive

Questa directory raccoglie le release pacchettizzate dell'app autonoma **GoSafe** (`com.smartboard.gosafe`), organizzate in sottocartelle per versione e pronte per la pubblicazione su [https://github.com/Alexander291938937/GoSafe/releases](https://github.com/Alexander291938937/GoSafe/releases).

## Struttura per Versione

Ogni sottocartella `<versione>` (es. `v1.0.0/`) contiene:
- `GoSafe-<versione>.apk` — Pacchetto Android pronto all'installazione sulla LIM (non compresso)
- `GoSafe-<versione>-apk.zip` — Archivio `.zip` contenente l'APK
- `GoSafe-<versione>-source-build.zip` — Archivio `.zip` pulito del repository GoSafe (README dedicato, logo & banner SVG, sorgenti Kotlin/Compose, risorse e file Gradle) pronto per `Alexander291938937/GoSafe`
- `RELEASE_NOTES_<versione>.md` — Note di rilascio pronte per GitHub Releases
